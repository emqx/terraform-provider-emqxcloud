# emqxcloud_deployment_api_key Resource

Create and retain one Deployment API key using Platform credentials. Refresh retains the local issuance record; remote updates, revocation and deletion are not supported.

~> **Warning:** The once-only App Secret remains in plaintext Terraform state. Refresh retains this local
issuance record and cannot detect remote revocation or permission drift. Inputs cannot change, and deletion
and replacement are blocked. Revoke the key in Console before explicitly removing its record from state.

Issuance requires Terraform 1.3 or later for destruction-plan safeguards, deployment management and the
separate `Deployment_API_Key` Platform service, and a running Dedicated or Dedicated Flex
deployment. There is a limit of five keys per deployment and two successful creations per hour per Platform
key. Explicit permissions are required. Uncertain writes are never retried; resolve incomplete issuance in
Console before attempting any new issuance. Clean dependent resources before revoking their key.
Existing key inputs must remain known and unchanged during planning, including when a missing deployment would
otherwise be recreated.

Key creation is serialized within each Provider process, including independent resources sharing that process.
Coordinate writes to the same deployment from other Provider processes, Terraform runs, Console or API clients;
this local safeguard does not make backend key updates concurrency-safe.

A failed create with complete returned credentials retains a tainted record. After confirming the exact key is
usable in Console and both AK/SK are retained, run `terraform untaint` for this resource to keep it. Do not remove
its state and issue another key. Untainting cannot recover a missing secret.

## Example Usage

```terraform
terraform {
  required_version = ">= 1.3"

  required_providers {
    emqxcloud = {
      source  = "emqx/emqxcloud"
      version = "~> 0.3.0"
    }
  }
}

provider "emqxcloud" {
  alias = "platform"
}

variable "project_id" {
  type = string
}

variable "platform" {
  type = string
}

variable "region" {
  type = string
}

variable "deployment_version" {
  type    = string
  default = "v5"
}

variable "connections" {
  type    = number
  default = 1000
}

variable "tps" {
  type    = number
  default = 1000
}

variable "mqtt_user_id" {
  type = string
}

variable "mqtt_password" {
  type      = string
  sensitive = true
}

resource "emqxcloud_deployment" "main" {
  provider           = emqxcloud.platform
  project_id         = var.project_id
  platform           = var.platform
  region             = var.region
  connections        = var.connections
  tps                = var.tps
  deployment_version = var.deployment_version
  status             = "running"

  lifecycle {
    prevent_destroy = true
  }
}

resource "emqxcloud_deployment_api_key" "main" {
  provider      = emqxcloud.platform
  deployment_id = emqxcloud_deployment.main.deployment_id
  description   = "Terraform deployment management"
  whitelist = {
    "/api/v5/authentication/password_based:built_in_database/users" = ["GET", "POST", "PUT", "DELETE"]
  }

  lifecycle {
    prevent_destroy = true
  }
}

provider "emqxcloud" {
  alias                 = "deployment"
  deployment_endpoint   = emqxcloud_deployment.main.connection_info.api_endpoint
  deployment_api_key    = emqxcloud_deployment_api_key.main.app_id
  deployment_api_secret = emqxcloud_deployment_api_key.main.app_secret
}

resource "emqxcloud_authentication_user" "example" {
  provider     = emqxcloud.deployment
  user_id      = var.mqtt_user_id
  password     = var.mqtt_password
  is_superuser = false
}

output "deployment_id" {
  value = emqxcloud_deployment.main.deployment_id
}

output "connection_info" {
  value = emqxcloud_deployment.main.connection_info
}
```

## Schema

### Required

- `deployment_id` (String) Running Dedicated or Dedicated Flex deployment identifier. Cannot change after issuance.
- `whitelist` (Map of Set of String) Explicit Deployment API paths and allowed HTTP methods. Cannot change after issuance; omitted permissions are not granted.

### Optional

- `description` (String) Key description, at most 128 characters. Cannot change after issuance.

### Read-Only

- `app_id` (String) Issued Deployment API App ID (AK).
- `app_secret` (String, Sensitive) Deployment API App Secret (SK), returned only on creation and retained in plaintext Terraform state.
