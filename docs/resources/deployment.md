# emqxcloud_deployment Resource

Create and start or stop one Dedicated Flex deployment. Deletion is not supported.

~> **Warning:** This resource never deletes a remote deployment. A deployment can continue to incur charges after
it is removed from configuration. Transfer its Terraform state deliberately and assign a manual cleanup owner.
Clean managed Deployment resources while it is running before deliberately changing its status to stopped.

## Example Usage

```terraform
terraform {
  required_version = ">= 1.0"

  required_providers {
    emqxcloud = {
      source  = "emqx/emqxcloud"
      version = "~> 0.3.0"
    }
  }
}

provider "emqxcloud" {}

variable "project_id" {
  type = string
}

variable "platform" {
  type = string
}

variable "region" {
  type = string
}

variable "connections" {
  type = number
}

variable "tps" {
  type = number
}

variable "deployment_name" {
  type = string
}

variable "deployment_version" {
  type    = string
  default = "v5"
}

variable "status" {
  type    = string
  default = "running"
}

resource "emqxcloud_deployment" "current" {
  project_id         = var.project_id
  platform           = var.platform
  region             = var.region
  connections        = var.connections
  tps                = var.tps
  deployment_name    = var.deployment_name
  deployment_version = var.deployment_version
  status             = var.status

  lifecycle {
    prevent_destroy = true
  }
}

output "connection_info" {
  value = emqxcloud_deployment.current.connection_info
}
```

## Schema

### Required

- `connections` (Number) Concurrent connection capacity.
- `platform` (String) Cloud platform: aws, gcp, azure, aliyun, tencent, or huawei.
- `project_id` (String) Identifier of the Platform project that owns the deployment.
- `region` (String) Cloud region for the Dedicated Flex deployment.
- `tps` (Number) Transactions-per-second capacity.

### Optional

- `deployment_name` (String) Requested name, between 1 and 64 characters. Older Platform APIs may generate a different remote name.
- `deployment_version` (String) EMQX major version: v5 or v6.
- `status` (String) Desired deployment status: running or stopped.
