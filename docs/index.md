# EMQX Cloud Provider

The EMQX Cloud Provider uses two independent credential groups:

- The **Platform API** reads projects and deployments and manages Dedicated Flex deployment lifecycle and TLS.
- The **Deployment API** manages resources inside one EMQX v5 deployment.

Configure only the group required by the data sources and resources in the current Provider instance. Endpoint,
API key, and API secret must be configured together, and credentials never fall back between the two groups.

## Example Usage

```terraform
terraform {
  required_version = ">= 1.0"

  required_providers {
    emqxcloud = {
      source  = "emqx/emqxcloud"
      version = "~> 0.1.0"
    }
  }
}

provider "emqxcloud" {}

data "emqxcloud_projects" "current" {}

data "emqxcloud_deployments" "current" {}

variable "deployment_id" {
  description = "Optional deployment ID to read in detail."
  type        = string
  default     = null
}

data "emqxcloud_deployment" "selected" {
  count = var.deployment_id == null ? 0 : 1

  deployment_id = var.deployment_id
}

output "projects" {
  value = data.emqxcloud_projects.current.projects
}

output "deployments" {
  value = data.emqxcloud_deployments.current.deployments
}
```

Use aliases when one configuration manages Platform resources and one or more deployments:

```terraform
provider "emqxcloud" {
  alias = "platform"
}

provider "emqxcloud" {
  alias = "deployment"
}
```

The Provider reads credentials from its arguments or the corresponding `EMQXCLOUD_PLATFORM_*` and
`EMQXCLOUD_DEPLOYMENT_*` environment variables. API key identifiers are intentionally not marked Sensitive; API
secrets are. Treat both as credentials. Sensitive values and opaque JSON can remain in Terraform state because
`Sensitive` suppresses normal CLI display but does not encrypt state.

## Schema

### Optional

- `deployment_api_key` (String) Deployment API key. May be set with EMQXCLOUD_DEPLOYMENT_API_KEY.
- `deployment_api_secret` (String, Sensitive) Deployment API secret. May be set with EMQXCLOUD_DEPLOYMENT_API_SECRET.
- `deployment_endpoint` (String) HTTPS Deployment API endpoint, including /api/v5 for EMQX resources; user information, query strings, and fragments are not allowed.
- `platform_api_key` (String) Platform API key. May be set with EMQXCLOUD_PLATFORM_API_KEY.
- `platform_api_secret` (String, Sensitive) Platform API secret. May be set with EMQXCLOUD_PLATFORM_API_SECRET.
- `platform_endpoint` (String) HTTPS Platform API endpoint, including /public_api/v1; user information, query strings, and fragments are not allowed.

## Lifecycle Notes

- `emqxcloud_deployment` creates Dedicated Flex deployments but never deletes them.
- Terraform import is not supported in v0.1.0.
- Delete dependent resources in Rule, Action, Connector order.
- Platform deployment credentials do not provide Deployment API credentials. Configure each deployment separately.
